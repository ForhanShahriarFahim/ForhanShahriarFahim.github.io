# CLAUDE.md

The project conventions, hard rules, and verification steps for this site live in
[AGENTS.md](AGENTS.md). Read that file first: it applies to every agent working
on this repository. This file points to the shared guidance.

[CONTEXT.md](CONTEXT.md) is the current project overview and source map. Read it
at the start of every task, then inspect the relevant source files. Update it
when a durable fact, page, workflow, or project status changes.

Routine content edits (adding a publication, a news item, a note) are documented
in [CONTENT-GUIDE.md](CONTENT-GUIDE.md).

[DECISIONS.md](DECISIONS.md) records why the site is built this way, what was
rejected, and what is still open. Read it before revisiting a settled choice.
