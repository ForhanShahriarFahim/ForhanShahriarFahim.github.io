Read `AGENTS.md` and `CONTEXT.md` at the start of every task in this repository.
The former contains binding rules; the latter maps current site context to its
source files. Read the relevant source before editing. Update `CONTEXT.md` when
a durable fact, page, workflow, or project status changes, and run
`python check.py` after every change.

For the current one-page site, read `ONE-PAGE-ROADMAP.md` Current task, R13,
and Next task. R10–R13 are implemented locally; verify the progress log and
